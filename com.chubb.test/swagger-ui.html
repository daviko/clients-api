POST /api/client Save a new client ›

Registers a new client using the information provided in the request body.

Request body required

Client information to be registered. Content type: application/json

{
  "firstName": "John",
  "lastName": "Smith",
  "surname": "Johnson",
  "phone": "+1234567890"
}

Responses

CodeDescriptionMedia type
200Client successfully savedapplication/json
400Invalid client information—
500Internal server error—

Example response

{
  "success": true,
  "message": "Client saved with success"
}
